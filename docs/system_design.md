# 系统设计
## 系统描述
  这是一个网页系统，用来展示教员毛泽东的一生。

我已经将资料数据保存到了json文件中，保存json文件的目录为/Users/zhangpeng/Data/studies/datas/chairManMao/处理后资料/毛泽东年谱/textin/json
    json中的内容样式为 [{"age":6,"year":"1989","month":"01","day":"01","do":"xxx","annotation":"xxx"},{"age":7,"year":"1990","month":"01","day":"01","do":"xxx","annotation":"xxx"}]
    其中：
        age：类型为数值int，含义为毛泽东的年龄。
        year：类型为字符串str，含义为年份
        month：类型为字符串str，含义为月份，例如'01','12'
        day：类型为字符串str，含义为日，例如'01','12'
        do：类型为字符串str，含义为毛泽东所做的事情，即文中的正文内容
        annotation：类型为字符串str，含义为毛泽东所做的事情一些注释，即文中某些页底部的注释内容

后续我计划将这些数据导入到我的mysql中。

另外我已经生成了网页主页的效果图，保存在本项目web目录下的 home.html中。
网页UI的设计思想如下：
    星空山峰图片地址：https://h-tateyama.alpen-route.co.jp/_wp/wp-content/uploads/2019/05/4775f0ea75df135558411bdb067478c7.jpg
    将这张图片作为一个网站网页的背景图，但我想要在这张图片的星空上添加84颗不同颜色和大小，并且发光能够进行点击的星星，这些星星是五角星的形状，每一个星星代表从1893到1976这84年中的每一年。星星不能太靠近顶部，另外将星星的位置，由年份大小按照从左到右的顺序排列，最小的年份排在左边，所有星星的高度不要保持一致，但都应该高于低于下面3分之一出的山峰。
    在背景星空添加缓慢流动的蓝紫色星云，但星星和下面的山峰保持静止，蓝紫色的星云不应该出现在底部的山峰上，只应该出现在星空中。
    在页面的右上角距离右边框一段距离的地方添加一个胶囊形状的输入框,用户输入某个年份,例如 '1905', 1905年的那个星星就会持续高亮。
    当鼠标不悬停的时候，只是偶尔随机几颗星星会发出微弱的光芒，鼠标悬停的时候，才会有放大发光，弹出气泡显示年份。
    当鼠标悬停某个星星，弹出气泡显示年份和xx岁，例如 悬停1893的星星，就显示  1893 0岁，0岁在1893的下面。
    当点击某个星星：触发波纹扩散动画，星星被"选中"并持续高亮1秒后，产生一个类似于时空隧道的特效，跳转到另外一个界面，再次点击则回复原样。另外一个界面会显示，教员在这一年所作的事情，有清晰的月和日期，数据来源为一个json文件，举例1905年.json。当然不能直接以json的格式进行展示，要以上传的图片作为json中第一件事的背景，下面以毛笔字的楷书展示其所作的内容。页面下方是一个左右可滑动的栏，显示的是json中所有的月份，当用户选择3月，3月就放大，同时页面左边显示该月所有有数据的日子，用户选择之后就展示该日对应的内容。
